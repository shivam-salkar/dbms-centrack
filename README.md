# dbms-centrack

Census Tracker - Government of India National Population Register System.

A comprehensive Flutter application for census tracking, population register management, and demographic data collection.

## Features

- **Phase 1 Data Entry**: House listing and housing census operations.
- **Phase 2 Data Entry**: Population enumeration and individual demographic data collection.
- **Analytics & Dashboard**: Interactive visual dashboards and statistics powered by `fl_chart`.
- **Progress Tracking**: Real-time enumeration progress and regional coverage reports.
- **State Management**: Scalable reactive state management using `provider`.
- **Theming**: Seamless Light and Dark mode support.

## Getting Started

### Prerequisites

- Flutter SDK (3.12+ recommended)
- Dart SDK

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/shivam-salkar/dbms-centrack.git
   cd dbms-centrack
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```

4. Run tests & analysis:
   ```bash
   flutter analyze
   flutter test
   ```
